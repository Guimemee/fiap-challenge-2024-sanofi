## 1. Enunciado e Instruções do Professor

**Conversão do Site para Aplicativo Mobile com React Native**

**Objetivo: **Deverão converter o site desenvolvido nas entregas anteriores em um aplicativo mobile utilizando **React Native**, com base nos conceitos abordados em aula. O aplicativo deve conter no mínimo 5 telas, seguindo a estrutura já existente no site. A comunicação com o backend não é obrigatória, mas será considerada um diferencial positivo caso seja implementada.

**Requisitos:**

* **Conversão para Mobile:** Transformar as funcionalidades e a interface do site estático desenvolvido nas Sprints anteriores em um aplicativo mobile utilizando **React Native**.
* **Navegação entre Telas:** Implementar uma navegação funcional entre, no mínimo, 5 telas. As telas devem refletir a estrutura do site, mantendo as seções principais já criadas (ex: Home, Formulário, Sobre, etc).
* **Formulário e Interatividade:** O formulário presente no site deve ser implementado no aplicativo, mantendo ou melhorando as validações e o feedback visual já desenvolvidos.
* **Uso de Componentes Reutilizáveis:** Aplicar os conhecimentos de **componentização** em React Native, organizando o código para que haja reutilização de componentes sempre que possível.
* **Funcionalidades Extras (Opcional):** Implementar comunicação com o backend (caso tenha sido desenvolvido em Sprints anteriores) ou adicionar funcionalidades extras que enriqueçam a experiência do usuário no app.
**Critérios de Aceitação:**

* O aplicativo deve ser funcional, com navegação fluida entre pelo menos 5 telas.
* O design deve ser adaptado para mobile, garantindo responsividade e boa experiência de usuário.
* O código deve seguir boas práticas de organização, utilizando componentes reutilizáveis e estilização adequada.
* O formulário deve ser funcional, com validações e feedback visual.
* **Diferencial:** A comunicação com backend será considerada um “**plus”**, caso seja implementada.
